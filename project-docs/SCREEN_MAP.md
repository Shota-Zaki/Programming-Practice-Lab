# SCREEN_MAP.md

## 目的

Programming Practice Labの主要画面を、正式機能の実装前に同一の情報設計とビジュアル体系で確認できる状態へ揃える。

## 主要画面

1. ホーム
2. プロジェクト一覧
3. プロジェクト詳細
4. 学習工程
5. 教材
6. 演習
7. 演習結果
8. 復習
9. 学習履歴
10. 開発環境

## 画面間の主導線

```text
ホーム
├─ プロジェクト一覧
│  └─ プロジェクト詳細
│     └─ 学習工程
│        ├─ 教材
│        ├─ 演習
│        │  └─ 演習結果
│        └─ 開発環境
├─ 復習
│  ├─ 教材
│  └─ 演習
└─ 学習履歴
```

## 設計上の境界

- 教材と演習は分離する。
- 演習結果は正否だけでなく次の修正へ接続する。
- 復習は間違い、迷い、経過時間を基準にする。
- 履歴は学習時間だけでなく、完成工程、テスト、技術経験を示す。
- 開発環境はブラウザ演習からローカル実務演習への移行画面とする。
- 現在の画面内採点と環境確認はUI確認用であり、本番基盤ではない。
