# Programming Practice Lab

実際にコードを入力し、実行・検証しながら、現場で利用される開発技術を学ぶための独立学習サイトです。

## 公開URL

- GitHub Pages: `https://shota-zaki.github.io/Programming-Practice-Lab/`
- 公開元: `main` ブランチの `/docs`

## 開発方針

- 開発作業は恒久作業ブランチ `work` で行う。
- 公開対象は `main/docs` とする。
- `/docs` は生成物であり、原則として直接編集しない。
- ソース変更時は必ずビルドし、更新された `/docs` を同じ変更に含める。
- `main` に統合された内容がGitHub Pagesの確認対象になる。

詳細はリポジトリ内の設計・運用文書を参照してください。
